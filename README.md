# Koko KMP Contest Starter Kit Documentation

Documentation site for the Koko KMP Contest Starter Kit, a Kotlin Multiplatform + Compose Multiplatform starter kit for building apps on Android, iOS, Desktop, and Web from one codebase. It ships with pre-built essentials such as user authentication, in-app purchases, push notifications, UI components, screen generation, and more, so you spend your time on your app instead of setup.

The starter kit codebase lives at [KotlinFoundation/kmp-contest-starter-kit](https://github.com/KotlinFoundation/kmp-contest-starter-kit).

Built with [Docusaurus](https://docusaurus.io/).

## Local development

```bash
npm install
npm start
```
